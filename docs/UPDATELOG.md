# BondForge 업데이트 내역

## 2026-10-28

### 0.1.0 — 첫 구현

- H, B, C, N, O, F, Cl 원자를 놓고 결합을 만들 수 있는 3D 분자 제작대를 만들었습니다.
- 단일·이중·삼중 결합을 만들고, 결합을 클릭해 차수를 바꾸고, 원자와 결합을 삭제할 수 있습니다.
- 원자가·옥텟·형식 전하를 계산해 한국어로 알려 주고, H 채우기로 남은 원자가만큼 수소를 붙일 수 있습니다.
- VSEPR 입체수 2–4를 지원하고, 전자 영역 기하와 분자 기하를 구분해 보여 줍니다.
- 이상 각도와 이 모형의 근사 각도를 함께 표시하고, VSEPR이 근사 모형임을 화면에 표시합니다.
- 결합 쌍극자를 벡터로 더해 CO₂·BF₃의 상쇄와 H₂O·NH₃의 극성을 구분합니다.
- C₄H₁₀의 두 구조 이성질체를 WL 해시와 정확한 동형 검사로 구분하고, 같은 구조를 두 번 세지 않습니다.
- 여섯 개 미션을 추가했습니다: H₂O 모양, CO₂ 극성, CH₄·NH₃·H₂O 비교, C₄H₁₀ 이성질체, BF₃·NH₃ 극성, C₂H₂ 삼중 결합.
- 미션마다 예측 게이트, 구조 확인, 근거 힌트, 해설, 한 줄 정리를 넣었습니다.
- 진행 상황, 예측, 완료한 단계, 찾은 이성질체를 브라우저 localStorage에 저장합니다.
- 교사 모드에서 정답·해설 보기, 3D 목표 구조 미리보기, 진행 초기화, 인쇄용 워크시트를 사용할 수 있습니다.
- 데스크톱 3열, 태블릿 점검 서랍, 휴대폰 하단 시트 레이아웃을 적용했습니다.
- 키보드로 원자 놓기, 결합 시작, 결합 완성, 삭제, 수소 채우기, 원자 선택 이동을 할 수 있습니다.
- 화면 읽기용 분자 요약과 알림 영역을 추가하고, 동작 줄이기 설정을 존중합니다.
- PWA 매니페스트, 오프라인 캐시, 앱 아이콘을 추가했습니다.
- 테스트: 화학·구조 단위 테스트 21개, 브라우저 상호작용 테스트 15개, axe 접근성 검사, 오프라인 재접속 검사를 통과했습니다.
- GitHub Pages 자동 배포 워크플로를 추가했습니다. main 브랜치에 push하면 빌드 후 Pages에 배포됩니다.
- 원자 팔레트 순서를 H, O, C, N, F, Cl, B로 바꾸고 모바일 팔레트의 중복 제목을 숨겨, 작은 화면에서도 첫 미션에 필요한 산소(O)가 바로 보이게 했습니다.
- 모바일 하단 시트에 목표·H 채우기·구조 확인을 모아 둔 미션 빠른 실행 바를 추가했습니다. 구조 확인 후에는 미션 탭으로 자동 이동해 피드백을 보여 줍니다.
- 키보드 배치 커서가 팔레트 조작 뒤에도 남아 분자를 가리던 문제를 수정하고 커서 크기를 줄였습니다.
- 빈 작업대에서는 점검 탭 경고 배지가 표시되지 않도록 했습니다.

### 참고

- B는 BF₃ 미션을 위해 원자 팔레트에 추가했습니다.
- C–H 결합처럼 전기 음성도 차이가 아주 작은 결합은 결합 쌍극자 목록에는 보이지만 분자 전체 극성 합에서는 제외합니다. 이는 이 모형의 작은 기하 오차로 뷰테인 같은 분자가 극성으로 잘못 표시되지 않게 하기 위한 교육용 근사입니다.
- 모든 계산은 브라우저에서 실행되며, 서버·API·AI 호출은 없습니다.
